# AutoYield – Automated Yield Distribution System
AutoYield tracks user balances and automatically distributes earned yield rewards
across participants based on their proportional holdings — no manual claiming required.

## Core Capabilities
- Auto-compounding yield tracking
- Proportional reward allocation across holders
- Deposit/withdraw synchronized with reward accounting
- Event logs for portfolio and dashboard tracking

## Key Functions
deposit, withdraw, distribute-yield, pending-rewards, get-balance
